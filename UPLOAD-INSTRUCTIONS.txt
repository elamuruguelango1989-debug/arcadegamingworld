MOBILE IMPROVEMENTS

1. Extract this ZIP.
2. Upload all website files and the assets folder into your GitHub repository beside index.html, replacing matching files.
3. Include mobile-v11.css and mobile-v11.js. Upload the contents, not the containing folder or ZIP.
4. Keep your existing CNAME file and custom-domain setting.
5. Commit the upload and wait for GitHub Pages deployment to finish. Refresh the site.

Changes: landscape racing road and controls side by side; larger Solitaire cards on narrow screens with a Fit board toggle; decorative horizontal page overflow clipped.

Checked using browser viewport layouts at 360px portrait and 844x390 landscape. This is not a real-device touch test.
