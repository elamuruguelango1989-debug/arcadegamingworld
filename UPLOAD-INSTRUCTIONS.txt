UPLOAD TO GITHUB
1. Extract this ZIP.
2. Open the arcadegamingworld repository and choose Add file > Upload files.
3. Drag ALL the extracted website files AND the assets folder onto the upload page. Upload the contents, not the ZIP or an enclosing arcade-refresh folder.
4. Files at the repository root should include index.html, about.html, contact.html, privacy.html, how-to-play.html, support-v7.css, refresh-v8.css, arcade-v8-refresh.js, and CHESS-LICENSE.txt. The assets directory must contain the SVG artwork.
5. Replace files with matching names and Commit changes.
6. Keep the existing CNAME file and your domain settings.
7. Wait for GitHub Pages deployment, then open https://arcadegamingworld.com/?v=8 in a fresh tab.

Full screen: open any game and select Full screen. Exit full screen returns to normal play. Some browsers use the expanded layout instead of hiding browser controls.

No advertising scripts or new analytics were installed. All prior game implementations remain included.
